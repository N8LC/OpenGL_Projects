<h2>
  Improved Raindrop Simulation
</h2>

This project is an upgrade of the [Raindrop Simulation](https://github.com/N8LC/Raindrop-Sim) project I made. Instead of using python for the logic and Tkinter for the visualization, I am using c++ & OpenGL respectively. The goal is to dramatically improve perfomance in order to create a more detailed simulation.

As with the original project, the idea is to create something similar to rain falling in the wind. This version of the project is more focused on creating a visually interesting verson of the project.

Since this project is just for fun it includes some vibecoding and AI assisted work. It is my first project using OpenGL, so I am using AI to help with the OpenGL parts.
